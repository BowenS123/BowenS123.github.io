# Bowen Liang — Portfolio Elektronica-ICT

Persoonlijk portfolio van Bowen Liang, student Elektronica-ICT aan PXL Hogeschool.
De website toont mijn ontwikkeling in embedded systems, elektronica, IoT, FPGA/SoC
en industriële automatisering.

## Live website

**[Bekijk het portfolio op bowens123.github.io](https://bowens123.github.io/)**

## Wat vind je op de website?

- Een korte introductie en overzicht van mijn technische vaardigheden.
- Uitgewerkte projecten met mijn bijdrage, resultaten en technologieën.
- Een projecttijdlijn van de opleiding.
- Een live overzicht van mijn publieke GitHub-repositories.
- Certificaten, contactgegevens en links naar mijn werk.

## Uitgelichte projecten

### Industry 4.0-verwerkingslijn

Een geautomatiseerde productielijn met Beckhoff TwinCAT, TwinCAT Vision voor
QR-scanning, MQTT-communicatie, een robotarm en een ESP32-mixer.

### LoRa GPS-tracker

Een IoT-project met ESP32, LoRa, GPS en een Raspberry Pi-dashboard voor het
verzamelen en visualiseren van sensordata.

## Lokaal uitvoeren

Omdat dit een statische website is, zijn geen packages of buildstappen nodig.

1. Clone de repository:

   ```bash
   git clone https://github.com/BowenS123/BowenS123.github.io.git
   ```

2. Open `index.html` in een browser, of start een lokale server:

   ```bash
   python -m http.server 8000
   ```

3. Open [localhost:8000](http://localhost:8000).

## GitHub Pages

GitHub Pages publiceert de website automatisch vanaf de `main`-branch. Wijzigingen
in `index.html`, `style.css`, `script.js` en `assets/` worden na een push naar
GitHub opnieuw gepubliceerd.
